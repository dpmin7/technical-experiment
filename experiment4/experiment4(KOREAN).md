## 목적

항공기 충돌 회피를 위한 거리 계산 알고리즘을 구현한다.  
선택된 두 항공기에 대해 CPA 거리/시간을 계산하고 소요 시간을 측정한다.  
또한 현재 수신 중인 모든 항공기 간 거리 계산을 수행하고 소요 시간을 측정한다. 
결과를 기반으로 소요 시간을 줄이는 방법을 고민한다.
프로젝트 적용 방안을 마련한다.

## 실험 설명

- 항공기의 위도, 경도, 고도,, 속도, 방향 데이터를 사용하여 두 항공기 CPA 거리/시간을 계산하는 함수를 실험한다.
    
- 기록된 항공기 데이터를 기반으로 전체 항공기 간 거리 계산 실험을 수행한다.
    
- 항공기 현재 위치를 기반으로 거리 계산이 불필요한 항공기를 제외하는 필터를 고민하여 실험한다.
	- 수평 거리 차이가 큰 항공기 제거 (Distance > 85NM)
		- 근거는 일반적인 항공기 최고 속도 500NM
		- 85NM 떨어진 거리의 항공기가 마주보고 접근 시 충돌하는데까지 걸리는 시간은 약 300초
		- 현재 시점에서 계산할 필요 없음
